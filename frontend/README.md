# Digital Heroes — frontend

The Next.js storefront, designer, customer account and admin console.

Setup, scripts and deployment are covered in the project [README](../README.md) and
[docs/DEPLOYMENT.md](../docs/DEPLOYMENT.md).

```powershell
npm install
```

```powershell
npm run dev
```

The frontend needs one variable in `.env.local`: `NEXT_PUBLIC_API_URL`, the address of the
backend API (default `http://localhost:4000`).
